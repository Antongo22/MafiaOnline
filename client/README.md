# 🎥 Клиент для видеозвонков SFU Engine

Современный веб-клиент для видеозвонков с поддержкой кода встречи.

## Возможности

- ✅ Создание встречи с уникальным кодом
- ✅ Подключение к встрече по коду
- ✅ Множественные участники
- ✅ Управление видео/аудио
- ✅ Текстовый чат в реальном времени
- ✅ Адаптивный дизайн
- ✅ Простой интерфейс

## Быстрый старт

### 1. Запустите сервер

```bash
# Локально
python main.py

# Или через Docker
docker-compose up
```

### 2. Откройте клиент

Откройте `index.html` в браузере или перейдите на `http://localhost:8000/client/index.html` (если настроили статику).

### 3. Создайте встречу

1. Введите ваше имя
2. Нажмите **"Создать встречу"**
3. Разрешите доступ к камере/микрофону
4. Скопируйте код встречи кнопкой **"Копировать"**
5. Отправьте код другим участникам

### 4. Присоединитесь к встрече

1. Введите ваше имя
2. Введите **код встречи** от организатора
3. Нажмите **"Присоединиться"**
4. Разрешите доступ к камере/микрофону

## Управление во время звонка

| Кнопка | Описание |
|--------|----------|
| 📹 | Включить/выключить камеру |
| 🎤 | Включить/выключить микрофон |
| 💬 | Открыть/закрыть чат |
| 📞 | Покинуть встречу |

## Чат

- Нажмите на кнопку **💬** для открытия чата
- Введите сообщение и нажмите **Enter** или кнопку отправки
- Все участники увидят ваши сообщения в реальном времени

## Тестирование

Для локального тестирования откройте несколько вкладок браузера:

1. **Вкладка 1**: Создайте встречу → получите код (например: `abc123def`)
2. **Вкладка 2**: Присоединитесь с кодом `abc123def`
3. **Вкладка 3**: Также присоединитесь с кодом `abc123def`

Все участники увидят друг друга!

## Технические детали

### Архитектура

```
Client → WebSocket → SFU Server → WebRTC → Other Clients
                         ↓
                     Media Relay
```

### Протокол WebSocket

**Отправка offer:**
```json
{
  "type": "offer",
  "sdp": "v=0...",
  "userName": "John"
}
```

**Получение answer:**
```json
{
  "type": "answer",
  "sdp": "v=0..."
}
```

**Отправка сообщения в чат:**
```json
{
  "type": "chat",
  "text": "Hello!",
  "userName": "John"
}
```

## Решение проблем

### Камера/микрофон не работают

1. Проверьте разрешения браузера
2. Убедитесь, что используется HTTPS или localhost
3. Проверьте, не используются ли устройства другим приложением

### Не видно других участников

1. Проверьте, что все используют один код встречи
2. Откройте консоль браузера (F12) для ошибок
3. Проверьте работу сервера
4. Убедитесь, что STUN сервер доступен

### Чат не работает

1. Убедитесь, что сервер обновлен и поддерживает чат
2. Проверьте WebSocket соединение
3. Посмотрите логи сервера

## Кастомизация

### Изменить STUN/TURN сервер

В `meeting-client.js` найдите:

```javascript
this.pc = new RTCPeerConnection({
    iceServers: [{ urls: 'stun:stun.l.google.com:19302' }]
});
```

### Изменить адрес сервера

В `meeting-client.js` измените:

```javascript
this.serverUrl = 'ws://localhost:8000';
```

### Изменить стиль

Отредактируйте CSS в `index.html` блоке `<style>`.
